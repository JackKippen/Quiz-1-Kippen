# Django Portfolio Project

This is a simple beginner Django portfolio website created for a college quiz.

## How to run the project

1. Open a terminal in the project folder.
2. Make sure Python is installed.
3. (Optional) Create and activate a virtual environment:

```bash
python -m venv venv
venv\Scripts\activate
```

4. Install Django if not already installed:

```bash
pip install django
```

5. Run the Django development server:

```bash
python manage.py runserver
```

6. Open a browser and go to:

```text
http://127.0.0.1:8000/
```

## Notes

- The site uses function-based views and HTML templates.
- No database content is required for the portfolio pages.
- The contact form is HTML-only and does not send messages.
